# Phase 04 — Portfolio list UI

**Phase 4 of 6. Depends on: phase 02. Blocks: phase 06.**

Delegate to OpenRouter (`ccr code`, coding tier).

## Goal
Build the Portfolio List screen per `docs/03-ui-and-figma.md`.

## Files (`lib/src/ui/`)

- `portfolio_list_page.dart` — `ConsumerWidget`. `Scaffold` → `CustomScrollView`/`Column` with: `HeaderSection`, `TabBarSection`, a row containing the title + `FilterIconWithBadge`, then `TraderList`.
- `header_section.dart` — plain `StatelessWidget`, title + banner placeholder. No Riverpod.
- `tab_bar_section.dart` — plain `StatelessWidget`, visual tabs only, no logic wired.
- `filter_icon_with_badge.dart` — `ConsumerWidget` that watches **only** `filteredCountProvider`; shows a filter `IconButton`; badge shows the count, and is hidden when the count is `null`. `onPressed` calls `showModalBottomSheet` — for now push a `const SizedBox.shrink()`; phase 05 swaps in the real sheet.
- `trader_list.dart` — `ConsumerWidget` watching `filteredTradersProvider`; `ListView.builder` of `TraderCard`.
- `trader_card.dart` — plain `StatelessWidget` taking a `Trader`. Layout:
  - row: `TraderAvatar` · name · `ApiBadge` (only when `isApi`)
  - `copiers/copiersMax` line
  - "30 Days PNL (USD)" + value, "ROI" + `roi`%
  - a 3-column row of `MetricCell`: **AUM**, **30 Days MDD**, **Sharpe Ratio** (Days Leading Trading is deliberately dropped — see docs/03)
  - a row of two buttons: `Mock` and `Copy` (visual only)
- `metric_cell.dart`, `api_badge.dart`, `trader_avatar.dart` — small plain widgets. `TraderAvatar` uses `Image.network` with an `errorBuilder` and `loadingBuilder` fallback (initials circle) — **required**, the reviewer may run offline.

Number formatting: thousands separators for money, 2 decimals; percents as `17.07%`. Put helpers in `lib/src/ui/format.dart`.

Wire `lib/main.dart`: `ProviderScope` → `MaterialApp(home: PortfolioListPage())`. Remove the counter scaffold.

## Rules
- Only `TraderList` and `FilterIconWithBadge` may `watch` a provider. Every other widget takes plain constructor params.
- No filtering/sorting logic in widgets.
