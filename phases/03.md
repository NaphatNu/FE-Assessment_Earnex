## Goal
Unit-test the state layer with `ProviderContainer` only — no widgets, no `pumpWidget`.

## Files

`test/filter_state_test.dart`
- empty filter matches every trader
- single tag matches only traders carrying it
- two tags behave as **OR** (union), never intersection
- `copyWith` and value equality

`test/providers_test.dart` — use a `FakeTradersRepository` overriding `tradersRepositoryProvider`
- `filteredTradersProvider` is `AsyncLoading` first, then filtered data
- applying a filter changes `filteredTradersProvider` and `filteredCountProvider`
- `filteredCountProvider` is `null` while loading
- **draft/applied separation:** mutating `draftFilterProvider` does NOT change `appliedFilterProvider` or the list; only `apply()` does
- **draft seeding:** a freshly built `draftFilterProvider` equals current applied value
- **autoDispose:** after the last listener of `draftFilterProvider` is removed, a new read returns the applied seed again (i.e. edits are discarded)

`test/mock_data_test.dart` — asserts the invariants of `assets/mock/traders.json` (parse it with `dart:io` File, not rootBundle):
- exactly 18 traders, ids unique
- every tag ∈ the 5 allowed values; 1–3 tags each
- every tag carried by ≥3 traders
- every tag **pair** OR-matches 5–9 traders

Delete the default `test/widget_test.dart` if it still references the scaffold counter app.
