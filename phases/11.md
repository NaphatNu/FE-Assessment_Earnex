## Task 1 — `phases/README.md`, standing rules

The rule as written is:

```
- Only `TraderList`, `FilterIconWithBadge` and `TagChipGroup` may `watch` a provider.
```

`SheetActions` watches `draftFilterProvider` too, and has since phase 05 — it needs it to know
whether `Reset` is enabled, which the Figma spec (`docs/05`, footer: `Reset` is
`state=disabled` until a selection exists) requires. The code is right and the rule is stale.
Replace it with:

```
- Only `TraderList`, `FilterIconWithBadge`, `TagChipGroup` and `SheetActions` may `watch` a
  provider. `SheetActions` watches `draftFilterProvider` because the Figma footer spec makes
  `Reset` disabled until the draft is non-empty. Every other widget takes plain constructor
  params.
```
