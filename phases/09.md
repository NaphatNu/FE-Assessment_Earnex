## Why this phase exists

## Task 1 — `format.dart`: top-level functions plus `badgeLabel`

`Format` is a class holding nothing but statics — in Dart that is a namespace workaround, and
top-level functions in a named file are the idiom. Convert:

- `Format.money(double)`   -> `String formatMoney(double value)`
- `Format.percent(double)` -> `String formatPercent(double value)`

Bodies unchanged. Delete the `Format` class. Update the four call sites in `trader_card.dart`.

Add, verbatim from the doc that decided it:

```dart
/// The text shown inside the filter badge, or `null` when the count is not
/// known yet (loading) — `null` means "unknown", `0` means "nobody passed".
String? badgeLabel(int? count) =>
    count == null ? null : (count > 99 ? '99+' : '$count');
```

## Task 3 — avatar fallback shows the initial

In `trader_avatar.dart`:

1. Add `required final String name;` to `TraderAvatar` and pass `trader.name` from
   `trader_card.dart` (`TraderAvatar(url: trader.avatarUrl, name: trader.name)`).
2. Extract the fallback into a **public** widget in the same file so it can be tested without
   the network:

```dart
/// Shown in place of the avatar image while it loads and when it fails —
/// the trader's first character on the brand circle.
class AvatarFallback extends StatelessWidget {
  const AvatarFallback({super.key, required this.name, required this.size});

  final String name;
  final double size;

  String get _initial {
    final trimmed = name.trim();
    if (trimmed.isEmpty) return '?';
    return String.fromCharCode(trimmed.runes.first).toUpperCase();
  }

  @override
  Widget build(BuildContext context) => Container(
        width: size,
        height: size,
        alignment: Alignment.center,
        decoration: const BoxDecoration(
          color: AppColors.bgBrand,
          shape: BoxShape.circle,
        ),
        child: Text(
          _initial,
          style: AppText.semiBold16.copyWith(color: AppColors.textPrimary),
        ),
      );
}
```

3. Point both `errorBuilder` and `loadingBuilder` at `AvatarFallback(name: name, size: size)`.
   `_fallback()` goes away. `runes.first` (not `name[0]`) so a multi-byte name such as
   `師429` yields `師`, not half a code unit. No new package import — `String.fromCharCode`
   and `runes` are `dart:core`.
