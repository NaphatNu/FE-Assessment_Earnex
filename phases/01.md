# Phase 01 — Data layer — model, mock asset, repository

**Phase 1 of 6. Depends on: nothing. Blocks: everything.**

Delegate to OpenRouter (`ccr code`, coding tier) — mechanical, spec is fully pinned below.

## Goal
Create the data layer: dependencies, `Trader` model, mock JSON asset, repository interface + asset implementation.

## Tasks

1. `pubspec.yaml`
   - dev_dependencies: add `mocktail: ^1.0.4`
   - under `flutter:` uncomment/add:
     ```yaml
     assets:
       - assets/mock/traders.json
     ```

2. `assets/mock/traders.json` — a JSON array of **exactly 18** trader objects with these keys:
   `id` (String), `name` (String), `avatarUrl` (String, https URL), `isApi` (bool),
   `copiers` (int), `copiersMax` (int), `pnl30d` (double), `roi` (double, percent e.g. 17.07),
   `aum` (double), `mdd30d` (double, percent), `sharpe` (double), `tags` (List<String>).
   - Allowed tag values, exactly these 5: `Top Performer`, `Money Maker`, `Consistent`, `Low Risk`, `Trending`.
   - Tag distribution constraints (these are asserted by tests in Phase 3, do not violate):
     - every trader has 1–3 tags; **no trader has more than 3 tags**
     - every tag is carried by **at least 3** traders
     - for any **pair** of tags, the OR-match count is **5–9** traders
     - at least one trader carries 3 tags
   - Values should look realistic (pnl30d 1,000–200,000; roi 2–60; aum 50,000–2,000,000; mdd30d 0.5–20; sharpe 0.5–4).

3. `lib/src/domain/trader.dart` — immutable `Trader` class: `const` constructor, all fields `final`, matching the JSON keys above, `factory Trader.fromJson(Map<String, dynamic> json)`. No `late`, no `!`, no `dynamic` fields. Add `==`/`hashCode` on `id`.

4. `lib/src/data/traders_repository.dart`
   ```dart
   abstract interface class TradersRepository {
     Future<List<Trader>> fetchTraders();
   }
   ```
   plus `class AssetTradersRepository implements TradersRepository` that reads
   `rootBundle.loadString('assets/mock/traders.json')`, `jsonDecode`s it and maps to `Trader`.
   Accept an optional `AssetBundle? bundle` constructor arg defaulting to `rootBundle` so tests can inject.
