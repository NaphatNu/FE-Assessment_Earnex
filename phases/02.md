## Goal

## Files

`lib/src/domain/filter_state.dart`
```dart
class FilterState {
  const FilterState({this.tags = const {}});
  final Set<String> tags;

  bool get isEmpty => tags.isEmpty;
  bool matches(Trader t) => tags.isEmpty || t.tags.any(tags.contains);   // OR within group

  FilterState copyWith({Set<String>? tags}) => FilterState(tags: tags ?? this.tags);
}
```
Add value `==`/`hashCode` (set equality) — the derived providers depend on it to avoid needless rebuilds.

`lib/src/providers.dart` (single file, all five):

| provider | type | notes |
|---|---|---|
| `tradersRepositoryProvider` | `Provider<TradersRepository>` | returns `AssetTradersRepository()`; exists so tests can override |
| `tradersProvider` | `FutureProvider<List<Trader>>` | `ref.watch(tradersRepositoryProvider).fetchTraders()` |
| `appliedFilterProvider` | `NotifierProvider<AppliedFilterNotifier, FilterState>` | **keepAlive** (default, NOT autoDispose) |
| `draftFilterProvider` | `NotifierProvider.autoDispose<DraftFilterNotifier, FilterState>` | `build()` returns `ref.read(appliedFilterProvider)` as its seed |
| `filteredTradersProvider` | `Provider<AsyncValue<List<Trader>>>` | `ref.watch(tradersProvider).whenData((l) => l.where(filter.matches).toList())` |
| `filteredCountProvider` | `Provider<int?>` | `filteredTradersProvider.valueOrNull?.length` |

Notifier APIs:
- `AppliedFilterNotifier`: `void apply(FilterState next)`, `void clear()`
- `DraftFilterNotifier`: `void toggleTag(String tag)`, `void reset()` (→ `const FilterState()`)

## Rules (enforced by review)
- Use `Notifier`, not `StateNotifier`/`AsyncNotifier`.
- No filtering logic in any widget — it lives only in `FilterState.matches`.
- `draftFilterProvider` must be `.autoDispose`; `appliedFilterProvider` must NOT be.
- No `ref.read` inside `build()` of a derived provider except the documented draft seed.
