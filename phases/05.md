## Goal
The Filter Bottom Sheet — the **core requirement** of the assessment: it must receive **zero** filter data through its constructor and talk to the global providers only.

## Files (`lib/src/ui/filter/`)

- `filter_bottom_sheet.dart` — `class FilterBottomSheet extends ConsumerWidget` with a **`const` constructor and no fields other than `super.key`**. Contents:
  - drag handle + "Filter" title + close button
  - `TagChipGroup`
  - static, non-wired controls drawn per design: Smart Copy toggle, PnL range, min ROI, time range (visual only, disabled)
  - `SheetActions`
- `tag_chip_group.dart` — `ConsumerWidget` watching `draftFilterProvider`; renders a `Wrap` of `TagChip` for the 5 tag values; tap → `ref.read(draftFilterProvider.notifier).toggleTag(tag)`.
- `tag_chip.dart` — plain `StatelessWidget`: `label`, `selected`, `onTap`. Selected state must be distinguishable by **more than colour** (e.g. check icon + border weight).
- `sheet_actions.dart` — `ConsumerWidget`:
  - **Reset** → `ref.read(draftFilterProvider.notifier).reset()`
  - **Confirm** → `ref.read(appliedFilterProvider.notifier).apply(ref.read(draftFilterProvider))` then `Navigator.pop(context)`

In `filter_icon_with_badge.dart`, replace the placeholder with:
```dart
showModalBottomSheet(
  context: context,
  isScrollControlled: true,
  builder: (_) => const FilterBottomSheet(),
);
```
The `const` here is the one-line, compiler-checked proof of decoupling (see `docs/02-widget-decoupling.md`).

## Test — `test/filter_bottom_sheet_test.dart`
- pump **`const FilterBottomSheet()` alone** inside a `ProviderScope` (no list page, no navigation) and assert the chips reflect `appliedFilterProvider`'s seeded value → proves it needs no parent
- tapping a chip changes `draftFilterProvider` but leaves `appliedFilterProvider` unchanged
- Reset clears the draft only
- Confirm copies draft → applied
- closing and reopening the sheet after editing without Confirm shows the applied value again (autoDispose discard)
