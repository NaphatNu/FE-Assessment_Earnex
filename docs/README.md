# docs

เอกสารในโฟลเดอร์นี้เป็นส่วนหนึ่งของงานที่ส่ง (commit เข้า git จริง)

ตอนนี้ยังว่างเปล่าโดยตั้งใจ — จะถูกเติมในเฟสถัดไป หลังจากที่มีการวิเคราะห์โจทย์ (requirement) แล้ว เช่น

- โครงสร้างสถาปัตยกรรม (architecture) ของแอป
- รายการหน้าจอ/หน้า (pages/screens) ที่ต้องมี
- แนวทางการจัดการ state (state management) ด้วย Riverpod

วัตถุดิบดิบ (โจทย์ต้นฉบับ, ลิงก์ Figma) สำหรับ AI ใช้อ้างอิงระหว่างทำงานอยู่ที่โฟลเดอร์ `.ai/` ที่ root ของ repo (ไม่ commit)
